<p>谈批发价，输的往往不是口才而是准备。同一家供应商，同样五十条静态住宅，有人拿到的是标价，有人拿到的是标价往下浮一档还带两条备用线，差别在于上桌之前有没有把三个数算清楚：要多少条、峰值并发多少、准备签多久。这篇不讲话术，只给一张可以照着填的清单，填完再谈，心里有底，也不容易被「送几条」「打个折」这类条件带偏。</p>

<h2>一、上桌之前必须先算清三个数</h2>
<p>三个数不清楚，谈出来的价格没有意义，因为套餐档位、计费口径、折扣空间全都挂在这三个数上。</p>
<h3>第一个数：要多少条</h3>
<p>按「承载付费订阅或业务数据的账号」来数，不是按注册总数数。十个账号里可能只有三个需要独享出口，剩下七个可以共用或走池子。数错了会多买一倍，用不上还占预算。</p>
<h3>第二个数：峰值并发多少</h3>
<p>并发指的是同一时刻有多少条出口在被使用。十个账号不等于十个并发，实际峰值常常只有三到五个。这个数决定要不要买带宽，也决定能不能用「共享端口+独立地址」这种更便宜的形态。</p>
<h3>第三个数：准备签多久</h3>
<p>月付灵活但单价最高，季付常见九折上下，年付视供应商能到八折甚至更低。周期越长折扣越大，但要留一条退路：先按月跑一个月，确认稳定再签长约。</p>

<h2>二、清单第一组：规模与档位怎么对上</h2>
<p>供应商的报价表通常按条数分档，档位之间的单价差异有时比折扣更明显。先看清档位，再谈折扣。</p>
<h3>常见档位长什么样</h3>
<p>多数报价表按十、五十、一百条分三到四档，跨档之后单价下降一截。如果计划买十八条，问一句「二十条档的单价是多少」，往往比在十八条上磨半天更有效。</p>

<h3>别把「送几条」当优惠</h3>
<p>赠品线路常见的问题是地区不对、类型不对、到期时间零散。谈的时候把赠品折算成等值现金看：送两条用不上的线路，不如单价降五个点。</p>

<h2>三、清单第二组：并发、带宽与地址形态</h2>
<p>这一组最容易被含糊过去，也最容易在后期产生额外账单。</p>
<h3>问清是「按条」还是「按端口」</h3>
<p>按条指的是一个地址一个凭据；按端口指的是一个入口多个出口。后者便宜，但并发受端口数限制，超了会排队。问一句「这个价格含几个并发」，比问单价更实用。</p>
<h3>带宽要不要单买</h3>
<p>轻量使用（每天几小时对话、少量附件）通常不需要额外带宽；涉及大文件传输、多人同时在线，才需要谈 10M 到 100M 的独享带宽。带宽按 Mbps 计费，价格区间跨度很大，务必让对方写清是独享还是共享。</p>

<p><strong>流量超了怎么算。</strong>有些套餐标称不限量但设了公平使用阈值，超阈值后限速。这条必须落到文字上：阈值多少、超了是限速还是加钱、加钱的单价是多少。</p>

<h2>四、清单第三组：合同、发票与变更条款</h2>
<p>价格谈下来只是前半场，条款决定后半场会不会返工。</p>
<h3>变更条款要看三条</h3>
<p>中途能不能换地址、换城市免费还是收费、换完是否重新计算周期。这三条在长期使用中一定会用到，提前写进合同能省掉很多争执。</p>
<h3>可用性与补偿怎么写</h3>
<p>不必追求夸张的承诺，写清「月度可用性低于多少可申请补偿、补偿形式是延长周期还是退款」就够。关键是有没有这条，而不是数字多漂亮。</p>
<p><strong>发票与结算周期。</strong>企业采购要提前确认能否开票、税率、开票周期。个人采购则要确认支付方式是否支持常用渠道，避免续费时卡在支付环节。</p>

<h2>五、清单第四组：把售后响应写实</h2>
<p>批发客户和零售客户拿到的支持往往不是同一个通道，这一点要当面问清。</p>
<h3>响应时效与通道</h3>
<p>问三件事：有没有专属对接人、工作时段是几点到几点、非工作时段的故障走什么通道。只写「7×24」没有意义，要问清夜间是人工还是工单排队。</p>
<h3>换线流程要能自助</h3>
<p>理想状态是后台能自助换址、能看每条线路的在线状态与流量。只能靠客服手动操作的供应商，在批量场景下会明显拖慢处理速度。</p>
<p><strong>留一份验收记录。</strong>首批交付后按清单逐条验收：地址数量、地区分布、类型、可用性、并发。记录留档，后续出现争议时有据可查。谈价谈得再好，交付不对等于零。</p>

<h2>常见问答</h2>
<h3>批量买是不是一定比单条便宜？</h3>
<p>答：通常是的，但便宜的幅度取决于档位和周期。跨档带来的单价下降往往比折扣更大，所以先问档位表、再谈折扣顺序更划算。也要注意低价套餐可能在带宽或换址次数上做了限制。</p>
<h3>年付折扣大，值得一次签一年吗？</h3>
<p>答：建议先按月或按季跑满一个完整周期，确认线路稳定、售后响应及时，再考虑年付。年付省下的钱，抵不上中途换供应商的迁移成本。</p>
<h3>并发数怎么估才不浪费？</h3>
<p>答：取最近两周的实际峰值，再上浮两成。多数团队的峰值并发远低于账号总数，按账号数买并发是最常见的浪费。</p>
<h3>谈价时最该坚持的一条是什么？</h3>
<p>答：把口头承诺写进合同，尤其是换址额度、可用性补偿和售后通道。价格可以让一点，条款不能让，因为条款影响的是长期成本。</p>
